# Décision Stack (pages 8-9 du PDF Clarté)

## Page 8 — Le modèle mental

```
        Vision            ↑
          │               │
       Stratégie          │
          │               how?
     Objectifs            │
        ╱│╲               │
  Opportunités            │
        ╱│╲               │
    Principes             ▼
```

- **Top-down** : chaque niveau spécifie *comment* le niveau au-dessus est implémenté
- **Bottom-up** : chaque niveau explique *pourquoi* le niveau en dessous existe

## Page 9 — Le pouvoir du "non"

Chaque niveau du Decision Stack implique des **"non"** explicites :

- Si tu priorises la **rétention** sur l'acquisition, le head of growth doit le savoir explicitement
- Donner une direction, c'est rendre les **"non"** visibles et assumés
- Sans "non", ce n'est pas une direction, c'est une liste de souhaits

**Ne pas confondre** clarté et certitude — la clarté est *plus* nécessaire quand la certitude manque.
